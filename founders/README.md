Tips
- Portrait crops work best (around 800×1000, face near the top). Keep each file under ~200 KB.
- Use freely licensed photos, for example from Wikimedia Commons (commons.wikimedia.org). Most require a credit line, so list the credits in `CREDITS.md` in this folder.
- Every card keeps its PARODY stamp so nobody mistakes the jokes for real endorsements.
